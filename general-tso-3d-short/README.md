# Курка генерала Цо — 30-секундний 3D-шортс · «Китайський Привіт»

Повний продакшн-проєкт вертикального мульт-шортсу (9:16, 1080×1920, 30 fps, 30 с) українською мовою.
Головний герой — Шеф Сян, перенесений із реальних фото у стилізований 3D.

У проєкті три частини:

1. **Продакшн-документи** — біблія персонажа, сценарій, промпти для генерації 3D-кадрів і сцен.
2. **3D-сцени, зібрані в коді** — персонаж Шефа Сяна, кухня, реквізит і анімація всіх п'яти сцен на
   Three.js / React Three Fiber (`src/three/`). Жодних зовнішніх генераторів чи моделей.
3. **Пайплайн збірки на [Remotion](https://www.remotion.dev/)** — зводить 3D-сцени (або готові відеокліпи), українську
   озвучку, музику, звукові ефекти, заголовки, плашки інгредієнтів і кінетичні субтитри в готовий MP4.

`npm run render` одразу дає повний ролик: 3D-сцени рендеряться з коду, озвучка, музика й ефекти вже лежать у `public/`.
Якщо згодом з'являться кліпи вищої якості (наприклад, згенеровані за промптами), покладіть їх у `public/scenes/` —
вони автоматично замінять відповідні 3D-плани.

## Структура

```
characters/
  chef_sian_3d.md             біблія персонажа: обличчя, уніформа, матеріали, заборони, QA-чекліст
  chef_sian_prompts.json      канонічний опис шефа + промпти turnaround sheet
  reference/                  сюди покладіть фото шефа (папка не комітиться)
scripts/
  general_tso_30s.json        сценарій: 5 сцен, озвучка, тексти, таймінги — єдине джерело правди для рендеру
prompts/
  scenes_3d_generation.json   7 промптів (сцена 2 — три плани) з вшитим описом шефа
src/
  three/Chef.tsx              3D-персонаж: кепка, сивина, «гусячі лапки», кітель, фартух, сабо; руки на інверсній кінематиці
  three/ChefSculpt.ts         голова, тулуб і фартух, виліплені гладкими цільними формами (SDF)
  three/sculpt.ts             «ліплення»: плавне злиття простих тіл і побудова сітки (marching cubes)
  three/Post.tsx              постобробка: ambient occlusion, глибина різкості, bloom, тонмапінг
  three/Kitchen.tsx           кухня: нержавійка, витяжка, круглий повітропровід, плитка, вок-станція
  three/Props.tsx             вок, полум'я, пара, шматочки курки, тесак, шумівка, миска, тарілка
  three/Shots.tsx             анімація 7 планів — чисті функції від номера кадру
  three/Turnaround.tsx        обертання персонажа на 360° для перевірки моделі
  components/                 заголовки, плашки, кінетичні субтитри, грейд / зерно / віньєтка
  timeline.ts                 таймінги, ретаймінг під озвучку, розклад звукових ефектів
public/

  sfx/                        звукові ефекти
  scenes/                     сюди — готові відеокліпи, якщо хочете замінити 3D-плани
tools/
  build-prompts.mjs           збирає обидва JSON із промптами з одного канонічного опису
  validate-script.mjs         перевіряє таймінги, безпечну зону і наявність опису шефа в кожному промпті
  scan-assets.mjs             знаходить медіафайли і міряє їх тривалість
  make-audio.mjs              синтезує музику і звукові ефекти (без зовнішніх файлів)
  tts_voiceover.py            локальний синтез української озвучки (Piper)
```

## Швидкий старт

Потрібні **Node.js 20+** і npm. FFmpeg окремо ставити не треба — він іде разом із Remotion.

```bash
cd general-tso-3d-short
npm install
npm run render
```

Результат: `out/general_tso_30s.mp4` — 1080×1920, 30 fps, 900 кадрів, H.264 (yuv420p, BT.709) + AAC.
Під час першого рендеру Remotion сам завантажить Chrome Headless Shell. Рендер іде через WebGL (ANGLE);
на машині без відеокарти він теж працює, просто повільніше (близько 1.5–2 с на кадр, тобто 25–30 хв на ролик).

Подивитися на персонажа з усіх боків: `npm run render:turnaround` → `out/chef_turnaround.mp4`.

## Звук

Усе вже згенеровано і лежить у репозиторії; перегенерувати можна так:

| Що | Команда | Примітка |
|---|---|---|
| Музика і звукові ефекти | `npm run audio` | синтез у Node: пентатоніка на «щипковій струні», 120 BPM, склейки в долю; шкварчання, удари тесака, спалах полум'я, «поп» плашок, дзвіночок |
| Озвучка | `pip install piper-tts`, далі `npm run voiceover -- --model шлях/до/uk_UA-ukrainian_tts-medium.onnx` | локальна модель Piper, голос `mykyta` (є ще `lada`, `tetiana`); де взяти модель — у шапці `tools/tts_voiceover.py` |

Текст для синтезатора — поле `voiceover_tts` у сценарії: малі літери і знак наголосу після наголошеної голосної.
Синтезований голос — робочий варіант: фрази сцен 1 і 2 дуже щільні, тому звучать поспіхом.
Для публікації краще записати живий голос і покласти файли під тими самими іменами в `public/audio/`.

## Як замінити 3D-сцени згенерованими кліпами

Кроки нижче потрібні, лише якщо ви хочете картинку вищої якості, ніж 3D із коду.

### 1. Референси
Покладіть оригінали фото шефа (без інтерфейсу телефона) у `characters/reference/` під іменами `IMG_3455.png` … `IMG_3464.png`.

### 2. Персонаж
Відкрийте `characters/chef_sian_prompts.json` і згенеруйте turnaround sheet у порядку з `consistency_workflow_uk`:
портрет з усмішкою → анфас / профіль / три чверті / ззаду → повний зріст у темно-синіх кроксах → аркуш деталей.
До кожної генерації прикріплюйте фото з `reference_images`. Кожен результат звіряйте з чеклістом у розділі 11 біблії.

### 3. Сцени
У `prompts/scenes_3d_generation.json` для кожного плану є:

| Поле | Для чого |
|---|---|
| `keyframe_start_prompt_en`, `keyframe_end_prompt_en` | стартовий і фінальний кадр (image-to-video) |
| `video_prompt_en` | повний промпт руху |
| `video_prompt_compact_en` | стисла версія до 2500 символів для інструментів із лімітом |
| `negative_prompt_en` | чого не має бути в кадрі |
| `parameters` | камера, світло, фізика вогню / пари / глазурі, безпечна зона |

Готові кліпи покладіть у `public/scenes/`:

| Файл | Слот | Тривалість слоту |
|---|---|---|
| `scene_01.mp4` | 00:00–00:03 | 3 с |
| `scene_02a.mp4`, `scene_02b.mp4`, `scene_02c.mp4` *(або один змонтований `scene_02.mp4`)* | 00:03–00:10 | 2 + 2 + 3 с |
| `scene_03.mp4` | 00:10–00:17 | 7 с |
| `scene_04.mp4` | 00:17–00:25 | 8 с |
| `scene_05.mp4` | 00:25–00:30 | 5 с |

Підходять також `.mov`, `.webm`, `.mkv`. Кліп довший за слот обрізається з кінця, коротший — сповільнюється до довжини слоту.
Зсув початку і швидкість задаються у сценарії: `video.trim_start_sec`, `video.playback_rate`.
Кліп не 9:16 обрізається по центру.

### 4. Озвучка
Запишіть або згенеруйте українську начитку за полями `voiceover` у сценарії. Два варіанти:

- **по файлу на сцену** (рекомендовано): `public/audio/vo_scene_01.mp3` … `vo_scene_05.mp3` (або `.wav`, `.m4a`).
  Пайплайн сам поставить кожну фразу в її слот, за потреби прискорить до ×1.35 без зміни висоти голосу
  і підтягне таймінги субтитрів та плашок під фактичну довжину фрази;
- **одна доріжка на 30 с**: `public/audio/voiceover.mp3`. Тоді субтитри йдуть за таймінгами зі сценарію (`subtitles[].start_sec / end_sec`).

Сцени 1 і 2 мають найщільніший текст (близько 7 складів на секунду) — начитуйте їх швидко й чітко.
`npm run assets` покаже, які фрази будуть прискорені, а які не вміщаються.

### 5. Музика
`public/audio/music.wav` (або `.mp3`) — зациклюється, звучить тихо під голосом (`meta.music.volume`), затухає в останню секунду.
Звукові ефекти дії (шкварчання, тесак, полум'я) прив'язані до 3D-планів і вимикаються для плану, який замінено кліпом.

### 6. Перегляд і правки
```bash
npm run studio
```
Відкриється Remotion Studio з таймлайном. Тексти, таймінги субтитрів і моменти появи плашок редагуються в
`scripts/general_tso_30s.json`, кольори — у `src/theme.ts`.

### 7. Рендер
```bash
npm run render          # out/general_tso_30s.mp4
npm run render:guides   # те саме з рамкою безпечної зони — для перевірки, не для публікації
```

## Безпечна зона

Увесь текст стоїть у центральній зоні **X 140–940, Y 260–1520**, яку не перекриває інтерфейс Shorts / Reels / TikTok.
Усередині зони — чотири смуги:

| Смуга | Y, px | Що там |
|---|---|---|
| Заголовок | 260–440 | назва кроку, шрифт Roboto Slab |
| Плашки інгредієнтів | 456–620 | з'являються, коли інгредієнт називає диктор |
| Чиста зона кадру | 640–1280 | обличчя шефа і головна дія — тексту немає |
| Субтитри | 1300–1520 | кінетичні субтитри, шрифт Jost |

Промпти сцен просять генератор тримати обличчя шефа і дію саме в чистій зоні, а взуття в загальному плані сцени 1 —
вище смуги субтитрів. Смуги мають фіксовану висоту з обрізанням, тому текст не може вийти за межі зони.
Шрифти вшиті в проєкт (`@fontsource`), інтернет для рендеру не потрібен.

## Як утримується схожість персонажа

- Канонічний опис Шефа Сяна існує в одному місці — `CHARACTER_LOCK_EN` у `tools/build-prompts.mjs`.
  `npm run prompts` дослівно вшиває його в кожен промпт сцени й turnaround.
- `npm run validate` (запускається перед кожним рендером) перевіряє, що опис присутній у кожному промпті
  і містить усі обов'язкові деталі: вік, кепку без логотипа, сивину на скронях, кнопки, фартух із биркою, сабо з біло-червоною смугою.
- Текст лише закріплює зовнішність; портретну схожість дають фото-референси і затверджений turnaround sheet.

## Якщо щось не працює

- **Remotion не може завантажити браузер** (закрита мережа). Вкажіть свій бінарник:
  `REMOTION_BROWSER_EXECUTABLE=/шлях/до/chrome-headless-shell npm run render`.
- **Linux без графічних бібліотек.** Встановіть залежності Chrome: <https://www.remotion.dev/docs/miscellaneous/linux-dependencies>.
- **Рендер повільний.** Додайте `-- --concurrency=4` або зменшіть якість: `-- --crf=22`.
- **Чорний кадр замість 3D.** WebGL не запустився — спробуйте `-- --gl=swangle` (програмний рендер).
- **Субтитр не вміщується.** Валідація не пропускає фрази, довші за 30 символів, — розбийте фразу на дві.

  платна Company License: <https://www.remotion.dev/license>.
- **Згода шефа.** Ролик відтворює зовнішність реальної людини — отримайте письмову згоду Шефа Сяна на використання
  його образу в згенерованому контенті.
- **3D із коду — стилізація «вінілова фігурка».** Персонаж виліплений гладкими формами і має всі фірмові деталі,
  але це не рівень повнометражної анімації і не портретна копія. Для такої якості використайте промпти й замініть плани кліпами.
- **Кольори бренду** в `src/theme.ts` підібрані на око (чилі-червоний, золотий, кремовий) — замініть на фірмові.
